# Brag Plan: Açaí Truck Delivery Bot

## What is this app?
A Telegram bot that lets NUS students order açaí bowls for delivery, backed by a full admin dashboard with payment verification, delivery session management, broadcast messaging, and a 1-hour auto-reminder system.

## The angle
We built enterprise-grade delivery infrastructure for an açaí truck. Real-time order tracking. Payment screenshot verification. Analytics dashboards. Automated reminders. For bowls.

## Hook (first 2-3 seconds)
Text slam: "Your açaí order." — pause — "...is now a Telegram bot." Clean white-on-purple. Fast cut.

## Key moments (the middle)
- Mock Telegram chat: user taps Order Now → picks flavor → uploads payment receipt → bot confirms
- The screenshot confirmation step: bot echoes back the receipt image asking "Is this the right one?"
- Admin dashboard: delivery orders table + analytics charts — real data, real UI
- Auto-reminder: "1 hour before delivery, everyone gets a reminder. Automatically."

## Outro / punchline
Logo + wordmark. Tagline: "Scrappy. Functional. Delicious." Beat drop to silence.

## User flow worth showing
Entry (user taps /start in Telegram) → picks delivery session + flavor + pays via QR → uploads screenshot → bot confirms → admin verifies → customer gets 1-hour reminder

## Tone
- Preset: yc-parody
- Creative direction: startup-level infrastructure for a humble açaí truck
- Interpretation: Deadpan seriousness applied to bowl ordering. Treat it like a Series A demo. Every feature presented as if it's disrupting logistics.
